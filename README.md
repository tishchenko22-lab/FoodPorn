# FoodPorn
Додаток для шефа.

## Оновлення бази меню

Додано SQL-файли для базової ініціалізації меню та нового оновлення від **15 квітня 2026**:

- `database/menu_base.sql` — створює таблиці `menu_categories` і `menu_items`, а також додає стартові категорії/позиції.
- `database/updates/menu_update_2026_04_15.sql` — додає нову категорію, нові страви, оновлює ціни та деактивує неактуальну позицію.

### Порядок застосування

1. Запустити базовий файл:

```bash
psql "$DATABASE_URL" -f database/menu_base.sql
```

2. Застосувати файл оновлення:

```bash
psql "$DATABASE_URL" -f database/updates/menu_update_2026_04_15.sql
```

### Що входить в оновлення 2026-04-15

- Додано категорію: `Сезонні пропозиції`.
- Додано позиції: `Хумус з пітою`, `Боул з лососем`, `Крем-суп зі спаржі`.
- Оновлено ціни для `Брускета з томатами` і `Паста Арабіата`.
- Позначено як неактивний: `Лимонад класичний`.

## Примітка

Усі `INSERT` виконуються через upsert-підхід (`ON CONFLICT`) для безпечного повторного запуску файлів.
